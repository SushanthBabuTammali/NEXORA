# Nexora

Nexora is a responsive AI intelligence homepage: an editorial view of AI stories, short explainers, model and company previews, and a personalized reading feed.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). For a production build, run `npm run build` and then `npm start`.

## Homepage interactions

- Search filters the sample stories and closes with Escape.
- The theme control switches between light and dark appearances.
- Story bookmarks and the follow control update the profile preview.
- The Sunday briefing form confirms locally; it does not submit an email address to a service.
- Navigation links move between homepage sections. Story, Moments, Models and Companies content is sample preview content for this first milestone.

The orb and feature artwork are CSS illustrations, so the page does not rely on remote image assets. No live news feed, accounts, database, native app or deployment is connected.
